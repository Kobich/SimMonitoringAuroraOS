# SIM Network Monitor — текущий scope

## Цель

Приложение для ОС Аврора показывает состояние SIM и мобильной сети: наличие SIM, состояние сети (отключена/2G/3G/4G/5G), оператора и диагностические данные, если они доступны ОС.

## Первый экран

- состояние SIM: готова, отсутствует, заблокирована или неизвестно;
- radio access type: сеть отключена, 2G, 3G, 4G/LTE, 5G или неизвестно;
- оператор;
- мощность сигнала в dBm;
- MCC/MNC;
- LAC/TAC, Cell ID и PCI — только если системный API и разрешения их отдают;
- время обновления данных.

## Что уже есть

- Flutter Aurora 3.35.7.2, PSDK 5.1.6.110, target `armv7hl`;
- проверенная RPM-сборка;
- UI с mock-данными;
- интерфейс `CellularDataSource`, отделяющий UI от нативной реализации.

## Реальные данные с устройства

Flutter сам по себе не умеет читать состояние модема. Следующий этап — реализовать `AuroraCellularDataSource` через D-Bus или Platform Channel, подтвердив на устройстве доступный API и permissions. UI и модель данных менять не потребуется.

## Пока не входит в scope

- Wi-Fi;
- управление SIM и мобильной сетью;
- история, карта и база сот;
- multi-SIM;
- режимы выше 5G.
